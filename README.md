# PriceWatch

Herramienta de seguimiento de precios de productos en múltiples tiendas y plataformas.

Permite registrar productos de cualquier categoría (tecnología, ropa, hogar...), asociarlos a las tiendas que elijas y mantener un historial completo de variaciones de precio a lo largo del tiempo.

## Características
- Categorías jerárquicas y etiquetas para organizar productos
- Soporte para múltiples tiendas por producto
- Historial de precios con estadísticas (mínimo, máximo, media)
- Sistema de alertas cuando el precio baja de un umbral
- Diseñado para escalar: arquitectura modular con API REST, scraping automatizado y sistema de colas

## Stack
`PostgreSQL` · `Python` · `FastAPI` · `SQLAlchemy` · `Docker`
